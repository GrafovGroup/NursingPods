# Supplier and product verification workflow

No supplier relationship is assumed and no supplier outreach has been sent.

1. Owner identifies the supplier contact and authorizes any outreach. Prepare a request for product documentation, Canadian supply/installation scope, product-specific access information, maintenance instructions, warranty terms and image rights.
2. Record each proposed item against `product-record.schema.json`. Leave unknown values null; keep `published=false`. Never use an invented SKU, dimension, certification, price or availability statement to complete a record.
3. Attach source evidence and its review date to each intended claim. Have technical/accessibility claims reviewed for the actual model and installation. A category title is not certification.
4. Obtain explicit permission for photos and any brand marks. Assign every photo to one locale/page/placement; update the asset register, check exact and visual duplicates and document inaccessible inventories. Do not reuse a photo for both languages.
5. Translate the approved facts into Québec French and review differences in meaning. Record owner and technical approvals.
6. Add a public item only after the evidence is complete. Current category pages remain useful planning guides until then. Optional per-locale imagery slots in ContentPage render only when an approved asset is explicitly assigned.
7. Revalidate availability, claims and rights before each material update. Archive superseded evidence privately; never commit contact lists, contract secrets or customer information.

Internal inquiry template (do not send without authorization): introduce NursingPods.ca using the verified legal entity, describe the project scope, request the documents above, ask what territory and work are actually supported, and ask for permission to use specific images. Do not claim an existing partnership.
