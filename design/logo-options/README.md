Open `index.html` for the review board or `comparison.png` for all five options together. These are review assets; the current public website logo is unchanged. Owner selection is in TOMORROW_OWNER_CHECKLIST.md. After selection, refine and produce final vector/favicons.

Flat vector-friendly logo design on solid warm ivory background. Deep teal symbol with restrained sage accent. Include exact wordmark 'NursingPods.ca' in refined highly legible modern sans-serif typography below or alongside symbol. No taglines, mockups, gradients, shadows, frames or extra text. One centered logo only, generous whitespace.”

The review board intentionally displays the five options together; it is an internal comparison artifact, not a set of additional website image placements. Images are raster design concepts until a direction is selected and finalized.
