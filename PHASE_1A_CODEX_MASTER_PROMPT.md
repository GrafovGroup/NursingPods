# NursingPods.ca — Phase 1A Codex Master Prompt

## Objective
Build a premium, bilingual (English and Québec French) Canadian B2B website for commercial nursing pods, lactation rooms, and private breastfeeding spaces. The primary conversion goals are **REQUEST A QUOTE** and **CALL NOW**. No prices, cart, checkout, or online payments.

## Development instructions
1. Inspect the repository and preserve any existing code. If empty, initialize Next.js with TypeScript and Tailwind CSS.
2. Build a production-ready, responsive, accessible foundation with reusable components, semantic HTML, and excellent mobile usability.
3. Create an original visual identity, distinct from other Grafov Group sites. Brand: **NursingPods.ca**. Tagline: **Private Spaces. Better Workplaces.** Palette: midnight teal #173B42, ivory #F8F6F1, sage #C5D6CC, copper #B47C62, charcoal #273238. Architectural, premium, welcoming; avoid generic baby-store styling.
4. Header navigation: PRODUCTS, SOLUTIONS, INDUSTRIES, LOCATIONS, ABOUT, CONTACT, EN/FR, CALL NOW, REQUEST A QUOTE. Include a mobile menu and footer.
5. Homepage sections: hero ("Private Nursing Spaces. Designed for Modern Workplaces."), product categories, practical benefits, industries, how it works, featured solutions, Canada-wide coverage, and final inquiry CTA.
6. Product category architecture: freestanding nursing pods, modular lactation pods, portable nursing pods, accessible nursing pods, custom nursing pods.
7. Solution architecture: workplace lactation rooms, nursing room design and fit-out, installation coordination, rentals, furniture and accessories.
8. Target buyers: airports, transit, universities, hospitals, corporate offices, shopping centres, government, convention centres, industrial workplaces, hotels.
9. How it works: explore solutions; describe your project; receive a tailored proposal; coordinate supply and installation.
10. English and French must be live from day one under /en/ and /fr/. Translate all navigation, content, CTAs, forms, validation, and metadata into natural Québec French. French headline: "Espaces d’allaitement privés pour les milieux de travail." Implement language switching, locale links, and en-CA/fr-CA hreflang.
11. Establish scalable SEO architecture for all Canadian provinces and territories, major cities, metro areas and surrounding municipalities, including Toronto/GTA and Montréal/Laval/Longueuil. Build foundations, not mass-produced thin location pages. Implement canonical URLs, unique metadata, sitemap, robots.txt, Open Graph, structured data with verified facts, and internal linking.
12. Add reusable inquiry UI with name, organization, email, phone, city, province/territory, product interest, project details, and timeline. Never simulate successful submissions: enable only when a real backend is connected. Keep business phone/email in centralized configuration and do not invent contact details.
13. Use premium, relevant imagery, clearly distinguishing conceptual visuals from real products. Do not invent inventory, supplier partnerships, prices, certifications, offices, reviews, or guaranteed fulfillment.
14. Ensure keyboard accessibility, contrast, meaningful alt text, reduced-motion support, responsive images, fast performance, and polished tablet/mobile views.
15. Phase 1A scope: brand identity, homepage EN/FR, responsive header/footer, reusable category/industry/CTA components, bilingual routing, SEO foundation, inquiry form UI, deployment-ready configuration. Defer complete catalogue, city-page expansion, and integrations to later phases.
16. Run available lint, typecheck, and build checks. Fix failures and document any remaining limitations.

Create `IMPLEMENTATION_REPORT_PHASE_1A.md` with completed work, changed files, routes/components, bilingual and SEO status, actual inquiry form functionality, tests/build results, configuration still required, known issues, and recommended Phase 1B scope.
